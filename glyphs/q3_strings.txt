# Console wording for CoD1 / UO on-screen text (English). Like CoD2 (padText in iw-pad.cpp), the DLL swaps these in
# its text draw hook only while the pad is in use, so keyboard players keep the stock text. The game's original line
# is found by REFERENCE. "main" = CoD1 base files (Main/, also read by UO), "uo" = UO's own (uo/).
# [%s] is filled by the game with the bound key (our button icon); [{cmd}] = the pad button bound to cmd.
# glyphs/q3_text.py turns this into src/q3_text.inc (original English line -> replacement).
# format: where|file|REFERENCE|new text
